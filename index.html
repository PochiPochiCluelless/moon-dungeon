manual

  • めあて エレベータで最上階(21階)まで昇る
  • 移動 矢印キー / WASD / 画面をドラッグ(攻撃は自動)
  • ダッシュ X を押しながら、やじるしキー(スマホはドラッグ)で移動。薄い壁をすり抜けられる
  • 必殺技 ゲージが満タンになったら Space(スマホは、キャラをダブルタップ)
  • X 調べる・話す・エレベータに乗る
  • アイテム 左上のアイコンをタップ(キーは Q・G・R)
  • T 首をかしげる(スマホは右の T ボタン)
  • 仲間の交代 左下の顔をタップ(Tab キー)
  • C 持ち物

赤い宝石の旅人は武器屋、緑の宝石の旅人は道具屋です。
